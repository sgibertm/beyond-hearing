# Data

The data is public and comes from the US **National Health and Nutrition Examination Survey (NHANES)**, run by the CDC. It isn't stored in this repository.

Download these four files from the **2017–2018** cycle on the [NHANES website](https://wwwn.cdc.gov/nchs/nhanes/) and place them in this folder:

| File | Questionnaire |
| --- | --- |
| `AUQ_J.xpt` | Audiometry (hearing) |
| `DEMO_J.xpt` | Demographics |
| `DPQ_J.xpt` | Mental health: depression screener |
| `SMQ_J.xpt` | Smoking: cigarette use |
